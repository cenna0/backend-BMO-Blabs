### Gate interpretation

The off-VPS destination, backup-key owner, all P9.1 secret ownership, and the
file-injection boundary are locked for the first canary. The actual manual
transfer, exact-copy restore, secret provisioning, and rotation rehearsals
remain acceptance gates. PR-16, PR-21, PR-25, and PR-27 require explicit
operator action before a canary. PR-19 is technically authorized and locked for
the first canary. No account, key, paid service, alert target, or production
credential is created by this branch.
