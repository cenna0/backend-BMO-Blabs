# P9.1 Windows Backup Procedure Implementation Plan

> **For agentic workers:** Execute this documentation plan inline in the isolated readiness worktree; do not install software, generate secrets, transfer backups, decrypt artifacts, merge, or deploy.

**Goal:** Lock a Windows/PowerShell/Tailscale/OpenSSH/Gpg4win manual off-VPS backup procedure for the first P9.1 canary.

**Architecture:** The operator pulls exactly three finalized files over the verified private Tailscale path using Windows `scp.exe`. PowerShell validates the encrypted artifact’s SHA-256 and sanitized manifest; GnuPG performs interactive readability testing; only a complete verified set is promoted from `incoming` to `verified`.

**Tech Stack:** Windows PowerShell, Tailscale, Windows OpenSSH `ssh.exe`/`scp.exe`, Gpg4win/GnuPG, SHA-256, existing P9.1 backup and restore policy.
